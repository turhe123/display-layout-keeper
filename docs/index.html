Features

Built for multi-monitor Macs.

Everything runs locally, with no accounts, servers or telemetry.

A layout per monitor setup

Each arrangement is identified by every display's UUID, pixel size and position, so layouts survive port changes.

Automatic snapshots

Windows are saved every 60 seconds by default (10 to 600), once the setup has been stable for 5 seconds, and again just before sleep.

Restore when displays change

After a configurable delay (3 seconds by default), windows return to their saved frames. Positions are clamped onto the nearest connected display.

Smart window matching

Windows match by app bundle ID and exact title, then fall back to window index. That keeps browser windows with changing tab titles in place.

Exclude apps you choose

Pick apps from /Applications that should never be saved or moved. Launch at login and auto-restore are simple toggles in Settings.

Private and local

Layouts are stored as JSON files on your Mac, capped at 20 configurations. Screen Recording is not requested.

Install

Up and running in a minute.

DisplayLayoutKeeper is open source and not notarized with a paid Apple Developer ID, so macOS needs one extra step the first time.

  1. Download DisplayLayoutKeeper-macOS.zip and unzip it.
  2. Move DisplayLayoutKeeper.app to your Applications folder.
  3. Clear the quarantine flag once, then right-click the app and choose Open:
    xattr -cr /Applications/DisplayLayoutKeeper.app
  4. When prompted, grant Accessibility access in System Settings → Privacy Security → Accessibility notifications are optional.

FAQ

Questions, answered.

Is DisplayLayoutKeeper free and open source?

Yes. It is free and released under the MIT license, with the full source on GitHub. If it saves you some headaches, you can support development through the Ko-fi link in the app.

What permissions does it need?

Accessibility is required so the app can read window titles, positions and sizes and move windows on restore. Notifications are optional and used only for a short confirmation after an automatic restore. It does not ask for Screen Recording, Camera or Microphone.

Where is my data stored?

Only on your Mac, in Application Support under DisplayLayoutKeeper/Snapshots, as one JSON file per monitor configuration. Nothing is sent anywhere, and you can delete any saved layout from the menu.

Why isn't the app notarized?

Notarization requires a paid Apple Developer account, which this free project does not have. Right-click the app and choose Open once to approve it, or build it yourself from source with Xcode.
